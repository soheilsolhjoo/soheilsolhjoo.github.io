# [HDFT](https://github.com/soheilsolhjoo/HDFT)
**Hot Deformation Fitting Tool** (HDFT) is a tool to calibrate various phenomenological models to study hot deformation's stress-strain data. The code is easy to use, and its therterical background is fully described in the following publication.
- S. Solhjoo, "Revisiting the common practice of Sellars and Tegart’s hyperbolic sine constitutive model: a critical note", Modelling 2022, 3(3), 359-373, doi:[10.3390/modelling3030023](https://doi.org/10.3390/modelling3030023).
